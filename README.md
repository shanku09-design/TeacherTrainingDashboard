# Teacher Training Tracker

Responsive role-based training tracker demo for Admin, Trainer, and Trainee workflows. The app and setup instructions are in [codebase/README.md](codebase/README.md).

## Run the demo

From the repository root:

```powershell
cd codebase
npm run start
```

Open http://127.0.0.1:4173 in a browser and sign in using one of the prefilled demo personas. Keep the terminal open while using the app.
